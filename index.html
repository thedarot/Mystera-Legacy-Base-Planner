Coded by GreyHope / Updated by Darot
What is it?
A base planner for Mystera Legacy that automatically calculates the cost in materials for your constructions.

How to use
1. Select an item/structure on the left sidebar
2. Left click to place on grass
3. Right click to remove
4. Shift + click to fill in line/area
5. Shift + Alt + click to erase some line/area

There are some tools
• Give a name to your project in the text field
• Use "💾 Save" to save as editable .json
• Use "📂 Load" to load previous project
• Use "📤 Export" to download an image with a material list (.jpg) or material list only (.txt)

Enjoy!
